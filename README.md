# fullstack-agent-lab

个人学习仓库：从前端到全栈，再到 Agent 应用工程。进度记在 Obsidian 总计划里，不在本仓库跟踪。

## 目录

- `event-signup/`：主练习项目，虚构的「活动报名与候补助手」。NestJS + Prisma + PostgreSQL，一路迭代到 Agent 阶段。
- `cs146s/`：精选的 Stanford CS146S 作业，改写成 TypeScript。稍后加入。
- `java-compare/`：和 Spring 的对照。最后加入。

## 工作流

每周一个分支、一个 PR，例如 `w01-event-persistence`。PR 描述里写测试命令和输出，作为证据。每个阶段打一个 tag，例如 `stage1-pass`。
